How this page works

Up
An expected answer came back quickly, on the first try.
Degraded
It answered, but slowly or only on the second try.
Down
No expected answer in two tries: a time-out, a refused connection, an error.

Uptime is the share of checks that were not down. Degraded counts as up, because slow is not out. Each bar is one day, in UTC; times on this page are in IST.

The checks are scheduled every 30 minutes and run on GitHub's servers, not Earnd's own, so this page stays up when the site does not. GitHub sometimes runs a scheduled check later than planned.
